# 배경 지우개

파일 하나(`index.html`)로 도는 배경 제거 도구. 설치도 서버도 없다.

어디를 지울지는 **사람이 브러시로 칠하고**, 무엇을 지울지는 **색 규칙이 고른다**.
기본은 안전 모드 — 칠한 영역 안에서도 밝은 무채색만 지운다.
자동 배경 제거가 못 가르는 흰 털·닫힌 배경(활대 안쪽, 후광 안쪽)을 손으로 정리할 때 쓴다.

## 쓰는 법

1. `index.html` 을 브라우저로 연다.
2. 그림을 끌어다 놓거나 [파일 열기]. 크롬·엣지면 [폴더 열기] 로 폴더째 열 수 있다.
3. 지울 자리를 브러시로 넉넉히 칠한다. **빨강** = 지워질 픽셀, **파랑** = 칠했지만 규칙에 안 걸린 곳.
4. [저장].

- 폴더로 열었으면 그 폴더 안 `배경제거/` 에 저장된다. 덮어쓰기를 켜면 원본을 `배경제거-백업/` 에 먼저 복사한다.
- 그 밖에는 내려받기로 나간다.
- 파일은 브라우저 안에서만 열린다 — 어디로도 올라가지 않는다.

자세한 도구·단축키는 화면의 [?] 도움말에 있다.
